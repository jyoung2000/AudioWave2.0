      Your data

      Accepts the player’s own event shape — { k, name, at, dur, meta: { artist, album, genre, tags } } — as a JSON array, or a CSV with columns at, kind, name, artist, album, genre, tags, seconds, length, finished, skipped, recommended. Exports use the same shapes, so a file round-trips.

      Every parameter the recommendation engine takes, with the engine's own names and its own limits. Nothing here is a simplification of the real settings — it is the settings. Move anything and the list beside it re-ranks. Save your own as an algorithm, and move algorithms between devices with Import and Export.
