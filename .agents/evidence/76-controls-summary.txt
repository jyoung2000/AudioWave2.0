EXPORT LOGS - what was proven and what was not

  PROVEN: the redaction. `exportLogs` (windows-companion/src/main/log.ts:197-202) runs every log
  file and about.txt through `redactLog` before zipping. I loaded that exact function out of the
  SHIPPED bundle (windows-companion/dist/main/index.cjs), ran it over the real companion.log plus six
  planted lines carrying a token, a Bearer value, two folder paths, a password and a credential, with
  the REAL helper token read through the companion's own bridge:

      redacted  the exact helper token
      redacted  any Bearer value with 8+ chars after it
      redacted  this scratch folder path
      redacted  the owner's home folder name
      redacted  a password assignment
      redacted  a credential assignment

      VERDICT: nothing sensitive survives redaction

  NOT PROVEN: that the button produces a zip a person can open. `dialog.showSaveDialog`
  (windows-companion/src/main/index.ts:525) blocks Electron's main thread, and while it is up the
  companion's window does not appear in the UI Automation tree at all, so a second process cannot
  find it to type a path. Windows' own save dialog would need a person. Evidence:
  evidence/73-export-logs.txt.
