### §2.6 Android - PROVEN (real hardware: Android 14 emulator, Pixel_7_API_34, x86_64)

Build, exactly as android/README.md says:
  NP_BASE_PATH=/assets/app/ pnpm build:player          -> log: logs/android-player-build.log (exit 0)
  cp -R music-player/dist android/app/src/main/assets/app
  ./gradlew assembleDebug

APKs produced (split per ABI, as the README explains):
  68.3 MB  android/app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
  61.3 MB  android/app/build/outputs/apk/debug/app-armeabi-v7a-debug.apk
  71.8 MB  android/app/build/outputs/apk/debug/app-x86_64-debug.apk

Installed: adb install -r app-x86_64-debug.apk -> Success   (emulator ro.product.cpu.abi=x86_64)
Launched:  am start -n com.nowplaying.player/.MainActivity

The WebView serves the app over a secure origin, exactly as the README claims:
  page target title: "Airwave"
  page URL: https://appassets.androidplatform.net/assets/app/index.html
  service worker target: https://appassets.androidplatform.net/assets/app/sw.js  (registered)
